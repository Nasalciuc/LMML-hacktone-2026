# Fry-ndship

Flag: `SIGMOID_PREDICTION` (alternative if rejected: `SIGMOID_SUPERVISION`)

Notebook: [fry_ndship.ipynb](fry_ndship.ipynb), figure: [edge_residuals.png](edge_residuals.png)

Short side = area / long side. Edge = 0.41 × rectangle perimeter + ditch + hedge, residual ±0.1 m. Plotting that residual against the fitted edge spells PREDICTION.

Two other layers: without the hedge the residual spells SUPERVISION (the hedge's own pattern), and the ditch lengths spell REGRESSION ([other_layers.png](other_layers.png)).
