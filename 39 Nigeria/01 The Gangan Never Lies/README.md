# Nigeria - The Gangan Never Lies

**Flag:** `SIGMOID_TALKINGDRUM`

The file sounds like plain noise and the sample LSBs are random (mean 0.50), so nothing there.
The average power per frequency band is flat except for a bump around 3.1-3.6 kHz.
A spectrogram of that band shows the word TALKINGDRUM written across the 10 seconds.
`python spectrogram.py` redraws it into `spectrogram.png`.
