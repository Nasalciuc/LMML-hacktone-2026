# LMML Hackathon 2026

One folder per country. Each task goes in its own subfolder, e.g. `45 Portugal/01 Douro Paradox/`.

Do `git pull --rebase` before pushing.

Datasets, audio/video and model weights are ignored (see `.gitignore`). If you really need one, `git add -f`. GitHub max is 100 MB per file.
